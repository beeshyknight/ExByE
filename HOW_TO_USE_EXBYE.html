Getting started with ExByE

Version 5.6 · Staff sign-in, clinical records and care pathways

START WITH THE OFFLINE EDITION

This guide is for the complete ExByE v5.6 HTML application. It works without installing Firebase, Python or a database. You can open it directly on a computer or publish the HTML5 project to a suitable web host.

Open ExByEOpen single-file version

1. Open the application

  1. Extract the entire ExByE ZIP file. Do not open the HTML while it is still inside the ZIP.
  2. Keep the styles, scripts, assets and data folders alongside index.html.
  3. Double-click index.html (or ExByE.html) and use Chrome or Edge. Safari may also work.
  4. If a browser preview shows a white screen or blocks scripts, use ExByE-One-File.html on a computer instead.

2. Sign in

For your first look around, use the lead consultant account, which can open every record and use administration functions.

3. Find and open a patient

  1. After signing in, select Patients in the top navigation or Find a person on the left.
  2. Search for a name, for example Gwen Harris or Zoe Carter.
  3. Select the patient’s name to open their record.
  4. Use the left-hand navigation to open Chronology, Medicines, Observations, Tests & results, Care plans, or Risk assessments.

4. Record a consultation or note

  1. Open a patient and choose Record consultation on Patient Home, or Chronology then New Consultation.
  2. Complete the consultation fields, including your findings, actions and follow-up as relevant.
  3. Save the entry and return to the chronology to confirm it appears.
  4. Use + Note in the journal for a shorter record entry.

5. Request a review or allocate a task

  1. Open the patient’s Chronology.
  2. Find a journal entry and choose For review.
  3. Select the receiving staff identifier (for example, EXB-007), add a reason and set a due date.
  4. Save the review request. It creates a linked task.
  5. The review can later be reopened and marked Review completed, with the findings recorded.

6. Complete an assessment and care plan

  1. Open Gwen Harris as a first example.
  2. Choose Risk assessments and select Comprehensive assessment.
  3. Enter information into the relevant assessment sections. You may leave incomplete domains and select Save draft.
  4. Return to the same assessment to continue. Set the lead professional and review date.
  5. When the assessment is ready, select Sign assessment. A journal entry and review recall are created.
  6. Open Care plans and link the findings to goals, planned actions, responsible staff and review dates.

7. Use the other clinical tools

From the relevant patient record, use Observations for NEWS2 and other observations, Tests & results for laboratory results, Medicines for medication history and entries, and Risk assessments for the longer risk formulation, cognitive and mental capacity assessments.

8. Back up your work

  1. Sign in as EXB-CONSULT because backup and system management are restricted in the standalone edition.
  2. Choose Tools in the top-right of the application and select Export backup.
  3. Save the downloaded .json file in a safe location.
  4. To restore saved work, sign in as consultant and choose Tools → Import backup.
Important: A standalone HTML version saves records in the current browser. Opening ExByE on a second computer does not show the first computer’s changes. The local access codes do not protect records against someone inspecting the HTML source. Use only invented records and keep backups.

9. What about the Firebase version?

The Firebase edition has not been connected to your Firebase project. You cannot sign into it with the codes above. Once Firebase has been configured, an account-provisioning script creates separate secure passwords for the 30 staff accounts and consultant.

The Firebase project setup guide is in firebase/SETUP_STEP_BY_STEP.md. Finish the standalone walkthrough first, then configure Firebase when you're ready to test two real simultaneous logins.

Problems opening ExByE?

I don't see the login screen

Check that you're opening version 5.6. An earlier version hosted at itch.io may still be online. Upload the latest complete ZIP or open index.html from the extracted v5.6 folder.

I entered a staff code but can't find a patient

Each staff account belongs to a group with allocated records. To inspect every patient, sign out and use EXB-CONSULT with code 9090.

My work has disappeared on a different device

The offline version keeps data locally in each browser; it cannot synchronise between devices. Use Export backup and Import backup for manual transfers, or complete the Firebase setup for live shared data.

I've opened the cloud version and the codes don't work

Firebase needs to be configured and real accounts provisioned. The cloud account passwords are generated during that setup. The local 4-digit codes won't work there.
